A mod for the Dummy13 x Clone Trooper figure that swaps the original pegs for backpack sliders, with modified chest and back plates plus a jetpack, a scuba jetpack and a commando backpack. It builds on TCTT's Dummy13 x Clone Trooper, Xero's Articulation Mod and Ben's Commando Mod.
